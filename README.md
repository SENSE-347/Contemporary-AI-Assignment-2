# Contemporary-AI-Assignment-2
# 实验二：搜索算法（A\* 与 Alpha-beta）

本仓库包含实验二四道题的实现、测试程序和实验结果。题目一、二使用 A\* 求最短路径或最小代价；题目三、四使用极大极小搜索与 Alpha-beta 剪枝求博弈树的最优值。

## 环境与依赖

- Python 3.12，开发与测试环境为 macOS。
- 题目一、题目三的代码与测试只使用 Python 标准库。
- 题目二的拓展实验（`extraTest_task2.py`）、题目四的实验程序（`test_treasure_game_task4.py`、`tt_h4_no_effect_task4.py`）需要 `matplotlib` 和 `scipy`。开发时使用的版本为 matplotlib 3.10.8、scipy 1.17.1。

安装命令：

```bash
pip install matplotlib==3.10.8 scipy==1.17.1
```

如果只运行题目一、题目三，不需要安装任何第三方库。

本实验没有外部数据文件。所有输入都在代码或用例文件中给出，随机地图由程序按固定种子生成，不需要下载或放置数据。

## 运行顺序

本实验没有训练过程。运行顺序为：先检查正确性，再运行评估实验，最后查看输出的预测结果。所有命令都在仓库根目录下执行。

```bash
# 1. 检查正确性
cd task1 && python3 test_maze_task1.py
cd task2 && python3 test_weighted_task2.py
cd task3 && python3 test_alphabeta_task3.py
cd task4 && python3 test_treasure_game_task4.py

# 2. 运行评估实验
cd task2 && python3 extraTest_task2.py
cd task4 && python3 tt_h4_no_effect_task4.py

# 3. 生成预测结果
# 题目一到题目四的预测结果由第 1 步的测试程序输出，
# 题目四的最优首步与收益差也会在第 1 步的输出中打印。
```

每个评估程序会在终端打印结果，并在所在文件夹写入对应的 `*_results.md` 与 `*.png`。图表与结果文件由程序生成，不要手动修改。

## 实验配置

- 随机种子：全部随机实验使用固定种子 2026。部分实验在此基础上加固定偏移量（例如 `SEED + 10 * k + H`），使不同实验使用不同的地图序列。
- 数据划分：本实验没有训练集与测试集之分。题目二的样本量估计使用同一随机序列的前 200 张地图作为预实验，最终统计使用同一序列中的全部地图（样本下限 300 张），并额外报告第 201 张之后的地图作为复核。
- 题目一：18 个测试用例，其中 17 个固定用例，1 个随机 20×20 用例。启发函数为曼哈顿距离，邻接方向为上下左右。
- 题目二基础要求：进入格子的代价为该格权值，E 的进入代价为 0，S 不可再次进入。启发函数为 `max(0, 曼哈顿距离 - 1) × 最小地形权值`。
- 题目二拓展：随机可达地图，规模 3 到 12，墙密度 0、0.15、0.3，权值 1 到 9。统计显著性水平 0.05，检验功效 0.80，Holm 校正。计时重复 3 次取最小值，每个方案最多样本量 2000。
- 题目三：9 个固定用例与 300 棵随机树，另有 5 个非法输入。节点计数包含根节点。
- 题目四：给定地图（H 为 1 到 4），以及 7×7 随机地图（墙密度 0.2，宝藏价值 6 到 9）。H 以"步"计，即一个玩家的一次选择为一步。同分时选择编号最小的宝藏。
- 置换表探究：穷举部分与地图无关；随机部分每组 200 张 7×7 地图，使用 Alpha-beta 搜索。

## 结果与提交

主要结果（完整数据见各 `*_results.md`）：

| 题目 | 关键结果 |
|---|---|
| 题目一 | 给定样例路径长度为 8 个坐标；曼哈顿启发扩展 13 个节点，h=0 扩展 15 个节点 |

## 复现与限制

核验方法：运行第一节"检查正确性"中的四个测试程序，若输出与下文预期一致，则实现正确。评估实验的数值由固定种子决定，相同代码应得到相同的节点数与统计结果。

预期输出（关键行）：

- 题目一：最后一行为 `18 cases passed`。
- 题目二基础版本：`15 cases passed`，随后 `random: 300 grids passed`。
- 题目二拓展：所有方案的最优代价与真实代价一致；实际可用最优为松弛启发函数。
- 题目三：`9 cases passed`、`random: 300 trees passed`、`bad inputs: 5 rejected`。
- 题目四：H=2 选 T2、收益差 -1；H=4 选 T3、收益差 3。
- 置换表探究：输出"穷举结果与推导一致"。

已知限制与可能的失败情况：

- 题目一：若仓库中的 `test_maze_task1.py` 没有修复 `load_cases`，用例 `wall_with_single_gap` 的地图会多出一行（`# 边界用例` 被误读为地图行）。修复后地图为 6 行。修复后的版本应当在仓库中使用。
- 题目一：随机用例没有预期长度，检查依赖 BFS 参考实现。
- 题目二：样本下限 300 张是人为选定的，不是公式要求的值。公式在所有两两比较中的最大需求为 69 张。
- 题目二：精确代价在 2 张地图上、地标启发函数在 4 张地图上扩展的节点多于修正曼哈顿。多出的节点都是 f 等于最优代价的平局节点，属于正常现象。结论只基于统计分布。
- 题目二：耗时数据在小地图上受系统噪声影响较大，松弛启发函数与精确代价的预计算耗时差异不作为结论依据。
- 题目三与置换表探究的节点数包含根节点；题目四的距离与对手策略实验不计根节点。比较数字时应只比较同一口径的结果。
- 随机实验只使用小规模地图（题目二为 3 到 12，题目四为 7×7），结论是否随地图增大而变化尚未验证。
- 置换表的命中条件（中间状态需 H≥5 且宝藏数≥5，终止状态需 H≥4 且宝藏数≥4）由推导和穷举得到，穷举范围为宝藏数 3 到 7、深度 2 到 6。
- 题目四若出现不可达的宝藏，代码会抛出 `ValueError`，不会返回结果。题目未规定这种情况。
